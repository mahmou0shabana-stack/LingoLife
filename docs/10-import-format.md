# 10. صيغة حزمة المشهد المُجهَّز

> **الوعد:** لا يُكتب في ذكرياتك شيءٌ لم تره على الشاشة أوّلًا. وما لا
> يستوعبه التطبيق يُعلَن بسببه ولا يُبتلَع صامتًا.

المسار الحقيقي الذي تعيشه هذه الصيغة:

```
تفريغ / صوت / صور / ملاحظات  →  ذكاء خارجي  →  حزمة  →  معاينة  →  استيراد
```

لا أن تُعيد إدخال ثمانيةَ عشرَ تعبيرًا واثنتَي عشرة جملة محادثة بيدك،
واحدةً واحدة *(بند 33)*.

---

## 10.1 الصيغة عقدٌ مع مُنتِجٍ خارجي

```js
export const PACKAGE_FORMAT_VERSION = 1;   // js/services/import/package-format.js
```

**منفصلٌ عن `TARGET_VERSION` عمدًا** — كما في صيغة النسخ الاحتياطي
(§7.1). الحزمة عقدٌ مع مُنتِجٍ لا يعرف شيئًا عن قاعدتك ولا يتابع
ترقياتها. فالقاعدة قد تترقّى عشر مرات وإصدار الحزمة كما هو.

| القاعدة | الحزمة |
|---|---|
| بنيةٌ داخليّة تتغيّر كل مرحلة | عقدٌ خارجيّ يتغيّر نادرًا |
| `TARGET_VERSION` | `PACKAGE_FORMAT_VERSION` |
| يكتبها التطبيق وحده | يكتبها مَن لا نتحكّم فيه |

**وصيغةٌ من المستقبل تُرفَض ولا تُقرَأ بقواعد اليوم.** حزمةٌ بإصدار 2
قد تحمل معانيَ لا نعرفها، وقراءتها بقواعد الإصدار 1 تعني تفسيرًا خاطئًا
**صامتًا** — وهو أخطر من الرفض الصريح.

## 10.2 مبدآن يحكمان القراءة

### كريمون فيما نقبل، صارمون فيما نلتزم به

مُخرَج الذكاء الخارجي لا يأتي بصيغةٍ واحدة: مرّةً `scene.title` ومرّةً
`scene.titleAr`، ومرّةً التاريخ `2026-04-01` ومرّةً طابعٌ رقمي. فالقراءة
تتسامح مع الأشكال المعروفة عبر `FIELD_ALIASES` و`COLLECTION_ALIASES`،
**والكتابة لا تتسامح أبدًا**: ما لا نفهمه يُرفَض بسببٍ مكتوب ولا
يُخمَّن.

| الحقل | الأسماء المقبولة |
|---|---|
| `title` | `title` · `titleAr` · `name` · `label` |
| `text` | `text` · `content` · `body` · `russian` · `ru` |
| `translation` | `translation` · `translationAr` · `ar` · `arabic` |
| `speaker` | `speaker` · `person` · `who` · `name` |
| `date` | `date` · `occurredAt` · `when` |
| `wrong` / `natural` | `before`/`after` · `mistake`/`correct` |

**والترتيب مقصود**: الاسم القانوني أوّلًا. مُنتِجٌ يرسل `title` و`name`
معًا يعني بالأوّل ما نعنيه، والثاني غالبًا اسم شيءٍ آخر.

والمجموعات كذلك: `speakers` و`people` و`persons` شيءٌ واحد، و
`conversations` تُقرَأ من مصفوفتها أو من `{ parts: [...] }`.

### الرفض بسببه لا بصمت

حزمةٌ فيها اثنتا عشرة جملة محادثة وواحدةٌ منها بلا نصّ: لا نستورد إحدى
عشرة ونسكت عن الثانية عشرة. نقول **«الجزء رقم 7 بلا نصّ»** — فتُصلحه
أنت أو تقبل استبعاده وأنت تعرف.

| المستوى | الأثر |
|---|---|
| `fatal` | يمنع الاستيراد كلّه — لا JSON، بلا مشهد، مشهد بلا عنوان، إصدار من المستقبل |
| `warn` | يستبعد عنصرًا ويُبقي الباقي — بترتيب العنصر في الحزمة |

وتاريخٌ لا يُفهَم لا يُخمَّن: مشهدٌ بتاريخ اليوم بدل تاريخه الحقيقي
يفسد ترتيب حياتك بلا أن تلاحظ، فيُقال لك.

## 10.3 ما يُستورَد وما لا يُستورَد

المواصفة *(بند 34)* تعدّ **أربعةً وعشرين** نوعًا. والتطبيق اليوم يمثّل
**سبعةً** منها تمثيلًا حقيقيًّا — له خدمةٌ تكتبها وشاشةٌ تعرضها.

### مدعوم بالكامل

| النوع | ترتيب الكتابة |
|---|---|
| `scene` | 1 |
| `people` / `speakers` | 2 |
| `eventThread` | 3 |
| `scripts` | 4 |
| `conversationParts` | 5 |
| `mistakes` | 6 |
| `expressions` | 7 |

الترتيب هو ترتيب التنفيذ: ما يُشار إليه يُنشَأ قبل مَن يشير إليه.

### جزئيّ — بحدوده المكتوبة

| النوع | الحدّ |
|---|---|
| `places` | يُؤخَذ الاسم في `scene.placeName`؛ المكان ليس كيانًا بعد |
| `translations` | تُؤخَذ مع السكريبت وجزء المحادثة، لا ككيانٍ مستقلّ |
| `eventType` | يُطابَق بنوعٍ عندك أو يُنشَأ — راجع §10.4 |

### مُعلَنٌ ولا يُستورَد

**هذه ليست قائمةَ إهمال بل إقرارٌ صريح** — كما `NOT_TRASHABLE` و
`EXCLUDED_STORES`. استيراد نوعٍ لا يعرضه شيء يعني **كتابة بيانات في
العدم**: تظنّ أنها وصلت وهي ليست موجودة. وهو أسوأ من عدم استيرادها.

| النوع | السبب |
|---|---|
| `media` · `mediaRoles` | ملفّات لا نصّ — تُضاف من الذكرى بعد الاستيراد |
| `words` · `sentencePatterns` | مستودعٌ بلا شاشة تعرضه |
| `colloquialLanguage` · `formalLanguage` · `professionalLanguage` | لم تُبنَ بعد كمجالات مستقلّة *(بنود 38–40)* |
| `topics` · `journeys` | مستودعٌ بلا خدمة |
| `projects` | **قرارُ منتَجٍ مؤجَّل عمدًا** — راجع docs/06 |
| `reviewSuggestions` | جدولة المراجعة لم تُبنَ بعد |
| `relationships` | تحتاج مشهدًا آخر موجودًا — تُربَط يدويًّا بعد الاستيراد |
| `analysisMetadata` | يُحفظ في تقرير الاستيراد لا كبياناتٍ في القاعدة |

> **حارسان بنيويّان.** اختبارٌ يمنع أن يدخل نوعٌ للمواصفة بلا قرارٍ فيه
> — إمّا مدعوم وإمّا مُعلَنٌ بسببٍ مكتوب وإمّا جزئيّ، لا رابع. وآخر
> يمنع أن يدخل بلا اسمٍ عربيّ، لأن المعاينة تعرضه لك بالاسم.

## 10.4 ثلاث طبقات

| الطبقة | السؤال | تلمس القاعدة؟ |
|---|---|---|
| `import/parse.js` | هل الحزمة سليمة الشكل؟ | ✗ |
| `import/plan.js` | ما علاقة ما فيها بما عندك؟ | قراءةً فقط |
| `import/apply.js` | اكتُبها | ✓ |

وفصل الأولى مقصود: التحقّق من الشكل يعمل على أي جهاز وفي أي وقت بلا
قاعدةٍ مفتوحة، فيمكن اختباره حتميًّا، ويمكن أن يخبرك أن الملفّ تالف
**قبل** أن نلمس بياناتك بشيء.

### الخطّة: نقترح ولا ندمج

«أحمد صلاح» في الحزمة و«أحمد صالح» عندك: الآلة ترى حرفًا فرقًا، وأنت
ترى شخصين أو شخصًا واحدًا — وأنت وحدك تعرف.

| الحالة | الفعل الافتراضي |
|---|---|
| نفس الاسم المطبَّع | `use-existing` — **هويّة لا دمج** |
| اسمٌ بديل عندك | `use-existing` |
| فرق حرفٍ أو حرفين | `create` **والقديم يُعرَض بديلًا** |
| اسمٌ جزءٌ من اسمٍ عندك | `create` والبديل معروض بسببه الخاصّ |
| لا شبه | `create` |

**الدمج الخاطئ يفسد سجلّ شخصين معًا، وفصلُ ما كان واحدًا تصلحه بضغطة.**
ولذلك ينحاز الافتراض للفصل.

والذكرى المكرّرة **تُنبَّه ولا تُلحَق تلقائيًّا**: حزمةٌ تُكتب في
الذكرى الخطأ تخلط حياتين لا تُفرَّقان بعدها بسهولة. والإلحاق فعلٌ
متاحٌ لك (`attach`) لا افتراضٌ منّا.

ومتحدّثٌ تكلّم في المحادثة ولم تُعرِّفه الحزمة يدخل الخطّة **غير
مُحدَّد**: لا شيء يضيع إن لم تُنشئه — اسمه يُحفَظ نصًّا كما هو، والربط
ممكن لاحقًا من «مين بيتكلم».

**ولكل قرارٍ دليلٌ مكتوب** يُعرَض بجانبه: «نفس الاسم بالضبط» · «اسمٌ
تاني عندك» · «الفرق حرف واحد» · «الاسم ده جزءٌ من اسمٍ عندك».

### التنفيذ: عبر الخدمات، وإمّا كلّه وإمّا لا شيء

كل كتابةٍ تمرّ بـ`createScene` و`addPerson` و`addType` و`addScript` و
`addExpression` — **لا بالمستودعات مباشرةً**. لأن الخدمات تحمل ما لا
تراه: الذكرى تُنشئ معها كتلة النصّ الأصلي، والسكريبت يُنشئ نسخته الأولى
في التاريخ، والتعبير كيانٌ عالميّ يُسجَّل له ظهور. استيرادٌ يكتب في
المستودع مباشرةً يُنتج صفوفًا **ناقصةً بصمت** — تبدو سليمة حتى تفتحها.

و IndexedDB هنا لا يعطينا معاملةً واحدة تلفّ عشرات الكتابات عبر
الخدمات. فيُمسَك **دفترٌ** بكل ما كُتب، ويُتراجَع عنه بالعكس عند أي
فشل:

- يسجّل **ما أنشأناه نحن وحده** — لا يُمحى صفٌّ كان موجودًا قبلنا أبدًا.
- ويسجّل ما **غيّرناه** في صفٍّ سابق بقيمته القديمة: معنى تعبيرٍ ملأناه
  يعود فارغًا كما كان.
- ويستعمل `destroy` لا `trash`: هذه صفوفٌ لم توجد قبل دقيقة، ووضعها في
  السلة يعني أن استيرادًا فشل يترك لك قمامةً تنظّفها بيدك.

**ولماذا كل هذا؟** لأن ذكرى بنصف محادثةٍ وبلا تعبيرات أسوأ من لا شيء:
تظنّها كاملة فلا تُعيد الاستيراد، ويضيع نصفها بلا أن تعرف.

## 10.5 المعاينة *(بند 36)*

`#/import` — ثلاث مراحل لا رابعة: **الصق ← عايِن ← استورد.**

الشاشة تجيب أربعة أسئلة قبل أي كتابة:

1. **إيه اللي جاي؟** أعدادٌ محسوبةٌ من **المقروء** لا من المكتوب في
   الحزمة.
2. **إيه اللي هيتعمل جديد وإيه اللي هيتوصّل بحاجة عندك؟** ولكل قرارٍ
   سببه بجانبه، وبدائله تحته.
3. **إيه اللي مش هيدخل؟** ما استبعدتَه أنت، وما لا يستوعبه التطبيق
   بسببه المكتوب.
4. **إيه اللي مش مفهوم في الحزمة؟** تحذيرات القراءة بأرقام عناصرها.

**ولا رقم بلا مصدر** *(بند 89)*: كل عددٍ يُحسَب من القرارات لحظة عرضه،
فلو استبعدتَ سبعةً نزل الرقم سبعة. والتقرير بعد الكتابة يُبنى من الدفتر
— ممّا كُتب فعلًا لا ممّا نُوِيَ — ويعرض ما له اسمٌ عندك وحده: نسخة
السكريبت وكتلة النصّ وظهور التعبير أجزاءٌ ممّا استوردتَه لا أشياءُ
استوردتَها، وعرضُها عدٌّ مزدوج.

## 10.6 مثال حزمة

```json
{
  "formatVersion": 1,
  "scene": {
    "title": "اجتماع الشحنة المتأخرة",
    "titleRu": "Встреча по задержке груза",
    "date": "2026-04-01",
    "place": "مكتب الشركة",
    "type": "اجتماع شغل",
    "context": "الشحنة اتأخرت أسبوعين والمورّد مش بيردّ."
  },
  "eventThread": { "title": "شحنة أبريل", "status": "active" },
  "speakers": [
    { "name": "إيجور", "role": "مدير اللوجستيات", "company": "ТрансЛогистика" }
  ],
  "scripts": [
    {
      "title": "الافتتاح",
      "text": "Добрый день, я по поводу задержки груза.",
      "translation": "يوم سعيد، أنا بخصوص تأخير الشحنة."
    }
  ],
  "conversations": [
    { "speaker": "إيجور", "text": "Груз задержался на таможне.",
      "translation": "الشحنة اتأخرت في الجمارك." },
    { "isMe": true, "text": "На сколько дней?", "translation": "كام يوم؟" }
  ],
  "mistakes": [
    { "wrong": "я ждать неделя", "natural": "я жду неделю",
      "kind": "grammar", "note": "الفعل يتصرّف والاسم في حالة النصب." }
  ],
  "expressions": [
    { "text": "по итогам переговоров", "meaningAr": "بناءً على نتائج المفاوضات",
      "register": "formal" }
  ],
  "analysisMetadata": { "by": "تحليل خارجي", "at": "2026-04-02" }
}
```

الحقول الملوّنة بالمرادفات كلها مقبولة: `speakers` أو `people`،
`conversations` أو `conversationParts`، `type` أو `eventType`، `place`
أو `placeName`، `kind` أو `mistakeType`، `note` أو `explanation`.

**والحقول المطلوبة قليلة عمدًا:** المشهد يحتاج عنوانًا، والشخص اسمًا،
والسكريبت وجزء المحادثة والتعبير نصًّا، والتصحيح نصفيه معًا — «قلت كذا»
بلا «الصح كذا» لا يعلّمك شيئًا.

## 10.7 الاختبارات

| الملفّ | يحرس |
|---|---|
| `tests/import.test.js` | الصيغة والقراءة — الرفض بسببه، والحارسان البنيويّان |
| `tests/import-plan.test.js` | «نقترح ولا ندمج»، و«المتطابق هويّة»، و**أن الخطّة لا تكتب شيئًا** |
| `tests/import-apply.test.js` | «عبر الخدمات»، و«إمّا كلّه وإمّا لا شيء»، وصدق التقرير |

وقواعدُها أُثبتت لا ادُّعيت: قلبُ «نقترح ولا ندمج» تجريبًا أسقط ثلاثة
اختبارات، وتعطيلُ التراجع أسقط خمسة.
