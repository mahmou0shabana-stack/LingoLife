# الاختبارات

## ⚠️ اقرأ ده الأول

الاختبارات **بتمسح قاعدة البيانات** على المتصفح اللي بتشغّلها عليه،
وبتبدّل خانتها عشان تجرّب الاسترجاع. وهي شغالة على **نفس النطاق** بتاع
التطبيق — يعني لو فيه ذكريات حقيقية على الجهاز، هتروح.

عشان كده فيه **بوابة تأكيد** لازم تضغطها بإيدك. مفيش حاجة بتشتغل
لوحدها من غير ضغطة، إلا لما يكون في الرابط `?run=1` (للأتمتة والـ CI).

**الآمن:** اعمل نسخة `.llife` من الإعدادات الأول، أو افتح الاختبارات في
**نافذة تصفّح خاص** — دي قاعدة بيانات منفصلة تمامًا ومش هتلمس حاجة.

---

## التشغيل من المتصفح

```bash
python3 -m http.server 8124
```

وافتح <http://localhost:8124/tests/>.

على التابلت من غير أي تنصيب: افتح `‎/tests/` على رابط الموقع المنشور.

---

## التشغيل بلا واجهة (اختياري)

Playwright **ليست اعتمادية للمشروع** — مفيش `package.json` ولا
`node_modules` في المستودع، والتطبيق مابيستوردش منها حاجة. تُثبَّت مؤقتًا
بره وتتوصل بوصلة رمزية:

```bash
mkdir -p /tmp/pw && cd /tmp/pw
npm init -y && npm install playwright && npx playwright install chromium
ln -sfn /tmp/pw/node_modules ~/LingoLife/node_modules

cd ~/LingoLife
python3 -m http.server 8124 &
node tests/run-headless.mjs http://localhost:8124
```

بيطبع النتيجة وبيرجع رمز خروج ≠ 0 عند أي فشل. ده اللي بيشتغل في CI برضه.

## الملفات

| الملف | الدور |
|---|---|
| `index.html` | الواجهة + بوابة الأمان |
| `backup.test.js` | 30 اختبارًا |
| `fixtures.js` | توليد عالم اختبار صناعي |
| `test-runner.js` | مشغّل صغير بلا اعتماديات |
| `run-headless.mjs` | التشغيل الآلي + فحص إقلاع التطبيق |
| `make-fixtures.html` | توليد ملفات ذهبية جديدة |
| `fixtures/*.llife` | الملفات الذهبية — **لا تُعدَّل أبدًا** |

## الملفات الذهبية

`fixtures/v1-minimal.llife` و`fixtures/v1-media.llife` نسخ أُنتجت بصيغة
v1 ومحفوظة في git **بلا تعديل للأبد**. قيمتها كلها في كونها أُنتجت بصيغة
ذلك اليوم لا بصيغة اليوم — فاسترجاعها بعد كل تغيير هو ما يثبت إن
التوافق الخلفي لسه شغال.

محتواها **صناعي بالكامل** (PNG بحجم 72 بايت، صوت وهمي، نصوص مخترعة)
لأن المستودع عام وأي حاجة تدخل git بتفضل في تاريخه للأبد.

لتوليد ملف ذهبي جديد بعد رفع `BACKUP_FORMAT_VERSION`: افتح
`/tests/make-fixtures.html`، واحفظ الناتج باسم يحمل رقم الصيغة الجديدة.
**متستبدلش القديم** — الاتنين يفضلوا.

المواصفة الكاملة في [docs/07-backup-format.md](../docs/07-backup-format.md).
