## التشغيل محليًا

ES Modules تحتاج خادم HTTP — لا تفتح `index.html` بنقرة مزدوجة.

```bash
python3 -m http.server 8124
```

ثم افتح <http://localhost:8124>.

## النشر

ادفع إلى `main` → GitHub Action يختم رقم البناء وينشر على GitHub Pages تلقائيًا.

**إعداد لمرة واحدة:** Settings → Pages → Source: **GitHub Actions**.

## الاختبارات

```bash
python3 -m http.server 8124
```

ثم <http://localhost:8124/tests/> — أو `‎/tests/` على الرابط المنشور،
فتعمل من التابلت مباشرةً بلا أي تنصيب.

⚠️ **الاختبارات تمسح بيانات المتصفح الذي تشغّلها عليه.** فيها بوابة تأكيد
لا تتخطّاها إلا بضغطة يدك. الآمن: افتحها في **نافذة تصفّح خاص**.
راجع [tests/README.md](tests/README.md).

## النسخ الاحتياطي

الإعدادات → **صدّر نسخة كاملة (.llife)**. ملف واحد فيه بياناتك وصورك
الأصلية وتسجيلاتك وإعداداتك.

على التابلت تظهر شاشة المشاركة فتختار **Google Drive** مباشرةً. الملف
أرشيف ZIP عادي — تقدر تفتحه بأي أداة وتشوف صورك حتى لو التطبيق اختفى.

الاسترجاع بيعرض **معاينة** الأول (متى اتعملت، كام سجل، كام ملف، أي
تنبيهات)، وبيتكتب في مساحة منفصلة — بياناتك الحالية مابتتلمسش غير لما
كل حاجة تنجح.

المواصفة الكاملة في [docs/07-backup-format.md](docs/07-backup-format.md).

## أين تُحفظ بياناتك

| النوع | المكان |
|---|---|
| كل بياناتك | **IndexedDB** باسم `lingolife` على جهازك |
| كود التطبيق | Cache Storage باسم `lingolife-<build>` |

المساحتان منفصلتان تمامًا. **نشر كود جديد لا يمسّ بياناتك** — وهذا مُختبَر
بثلاث عمليات نشر متتالية.

⚠️ **قاعدة حديدية:** IndexedDB مربوطة بالـ origin. لا تُعِد تسمية المستودع ولا
تنقل الموقع لرابط آخر إلا بعد تصدير كامل. تغيير الرابط = عالم جديد فارغ.

## الخلاصة في سطور

**المشكلة الجذرية:** الـ prototype يحفظ كل مشهد كنص JSON واحد (بصور Base64 بداخله) في تخزين مؤقت مرتبط ببيئة التشغيل — لذلك تضيع البيانات مع كل نسخة جديدة.

**الحل:** IndexedDB مُطبّعة على **رابط ثابت لا يتغير أبدًا**، + Google Drive كبيت سحابي دائم، + ترقيات schema غير مدمّرة، + تصدير `.llife` كامل.

**الأدوات:** GitHub (المصدر) → GitHub Pages (الاستضافة، رابط ثابت) → Claude Code على الويب (التطوير من التابلت). **بلا Replit وبلا Antigravity وبلا Firebase.**

**التكلفة الشهرية: 0 دولار. بلا بطاقة ائتمان.**
