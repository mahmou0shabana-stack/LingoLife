Per-voice measurements

RHVoice and Piper: wall time is the whole process for one sentence, model load included, because both CLIs start a fresh process each time. Piper's own log also reports pure inference time. The first call's page cache may already have been warm.
XTTS, Qwen3-TTS, Chatterbox, CosyVoice: the model is loaded once per voice in a persistent worker. Model load is that one-time cost; the first call of the first variant also includes it. Peak RAM is the worker's peak resident memory (CPU only, no GPU on this machine).

Stress marks (U+0301)

Every engine was run twice over the corpus: text as-is, and with U+0301 removed (the ~no-stress-marks voice in the selector). The neural engines used the same random seed per sentence in both runs. Different audio only shows that the marks changed the output. Whether the stress landed on the marked syllable is for your ears: compare the two variants of #04, #05, #06, #07 and #27 against #28. The determinism control repeats a sentence with no marks in both runs. Identical audio there means any difference in the marked pairs comes from the marks.
