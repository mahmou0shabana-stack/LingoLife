## المرحلة 1 — المشهد الكامل (قلب المنتج)

**الهدف:** إدخال مشهد حقيقي من حياتك بكل عناصره، والعودة إليه.

**1أ — الوسائط**
- رفع صور متعدد، **الأصل بلا ضغط**، thumbnails منفصلة
- أدوار الصور (غلاف/استرجاع/خط زمني) + إعادة ترتيب + Lightbox + تنزيل الأصل
- رفع صوت + **تسجيل داخلي (Opus)** + أدوار + تعيين أساسي
- مشغّل: سرعة، تكرار، Loop، تنقّل

**1ب — النصوص**
- سكريبتات غير محدودة + أساسي + نسخ/تعديل/تكرار
- **Raw Transcript محمي** + Version History للسكريبتات
- محادثة بأجزاء + تشغيل متسلسل
- **Before / Natural** بالشرح المصري ونوع الخطأ

**1ج — العرض**
- صفحة Journal كاملة + Mini Index
- **Focus View** (شاشة كاملة لكل قسم)
- **Journal Spread للتابلت**: الذاكرة \| اللغة
- NOW + My Life Timeline مجمّع بالشهر

**1د — الأساسيات**
- Active / Archived / Trashed + استرجاع + حذف بتأكيد يعرض المرتبطات
- Undo للإجراءات المهمة
- بحث محلي عبر كل المحتوى + Normalization (ё/е، تشكيل عربي)
- استعادة آخر مشهد وقسم بعد إعادة الفتح
- تصدير/استيراد `.llife` كامل

**معيار القبول:** تدخل مشهدًا حقيقيًا فيه 12 صورة و7 ملفات صوت و4 سكريبتات و3 أخطاء — وتعود إليه بعد أسبوع وبعد تحديثين، وكل شيء في مكانه.

## المرحلة 2 — عالم اللغة

**الهدف:** اللغة تصبح كيانات حيّة عابرة للمشاهد، لا نصًا داخل مشهد.

- ترحيل التعبيرات إلى `expressions` + `expressionOccurrences`
- **Expression Life** — الخط الزمني الكامل بتواريخه، وكل نقطة تفتح مشهدها
- تحليل التعبير الكامل (معنى مصري/حرفي/سجل/طبيعية/أين يُستخدم)
- Words + Sentence Patterns ككيانات
- **كل رقم قابل للنقر** — «ظهر في 7 مشاهد» تفتح السبعة فعلًا
- My Language بتصنيفاته
- Relationship Engine مُفعَّل

**معيار القبول:** تفتح تعبيرًا واحدًا وترى رحلته الكاملة عبر مشاهدك بالتواريخ — وكل رقم معروض قابل للإثبات بالنقر.

## المرحلة 3 — Google Drive

**الهدف:** بياناتك لها بيت دائم خارج الجهاز.

- OAuth عبر Google Identity Services (`drive.file`)
- اختيار/إنشاء مجلد Workspace + حفظ **Folder ID** لا الاسم
- `lingolife-profile.json` في appDataFolder
- هيكل المجلدات الكامل + `workspace.manifest.json`
- طابور مزامنة (dirty tracking + debounce) + حالات ظاهرة
- **استرجاع العالم عند فراغ الجهاز** — ولا إنشاء عالم فارغ تلقائيًا
- كشف التعارض وعرض النسختين
- شاشة إعدادات Drive كاملة + فصل الاتصال دون حذف

**معيار القبول:** تمسح بيانات المتصفح بالكامل → تسجّل دخولًا بنفس الحساب → «عالم LingoLife موجود: 127 مشهدًا…» → استرجاع → كل شيء يعود بما فيه الصور والأصوات الأصلية.

## سياسة الحالة الصادقة

بعد كل مرحلة يُحدَّث `STATUS.md` بثلاثة أقسام:

```
✅ يعمل           — مُختبَر على جهاز حقيقي
🟡 جزئي           — يعمل بحدود مذكورة صراحةً
⬜ غير منفَّذ      — الزر إما غير موجود أو موسوم "قريبًا"
```

**لا زر يبدو أنه يعمل وهو لا يعمل.** ولا رقم لا يمكن إثباته بالنقر.
